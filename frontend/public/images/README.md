# Images Folder

## Required Images:

### Hero Section:
- `patna-monument.png` - Patna monuments/cityscape background image (1920x1080 recommended)

### Category Icons:
You can use icon libraries or SVG icons instead of emojis.

## Where to Get Images:

1. **Patna Monuments**: 
   - Search for "Patna Gandhi Maidan"
   - "Patna Golghar"
   - "Patna Mahavir Mandir"
   - Use free stock photos from Unsplash or Pexels

2. **Icons**:
   - Use React Icons library (already supports SVG icons)
   - Or use Heroicons (Tailwind's official icon set)

## How to Add:

1. Download/create images
2. Place them in this folder
3. Update the Image src paths in components
