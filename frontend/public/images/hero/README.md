# Hero Background Images

This folder contains the default hero section background image.

## Required Image

**hanuman-bg.jpg** - Default homepage hero background with Hanuman ji statue

## Image Specifications

- **Dimensions**: 1920x600 pixels (recommended)
- **Format**: JPG
- **File Size**: Keep under 300KB for optimal performance
- **Subject**: Hanuman ji statue from the screenshot
- **Aspect Ratio**: 16:9 or wider

## Current Design

The default hero section features:
- **Title**: "Apna Bihar, Ab Aapki Khoj Mein!" (with "Aapki Khoj" highlighted in yellow)
- **Background**: Hanuman ji statue image
- **Overlay**: Blue overlay (rgba(6, 43, 73, 0.75)) for text readability
- **Stats**: 5000+ Businesses, 50+ Categories, 10K+ Reviews, 100K+ Users

## Usage

This image will show on the homepage when no festival is active. During festivals (Diwali, Holi, etc.), festival-specific banners from `/images/festivals/` will be used instead.
